# T-0023 — Оставшиеся вопросы вынесены в грилл-тикет (GitHub #245)

- **Категория:** процесс / передача решений человеку
- **Статус:** DONE (issue создан)
- **Дата:** 2026-10-01, цикл 8
- **Связь:** GitHub issue **#245** (метка `wayfinder:grilling`)

## Что сделано

Все оставшиеся решения, которые нельзя принять без человека, сведены в один
грилл-тикет по формату скилла `grilling`:

- **Round 1 (frontier)** — 11 вопросов с вариантами и рекомендациями: включение
  набора в CI, источник правды по Python-окружению, владелец оптимизации
  демо-сидера, покрытие frontend, линтер, параллельный Playwright,
  `@testing-library/jest-dom`, судьба веток/worktree, push в `origin`,
  дубликат `test:pytest:fast`, продуктовые Pydantic-предупреждения;
- **Следующие раунды** — вопросы, зависящие от ответов первого (порог покрытия,
  место линтера в CI, регистрация `ktm_mig_*`, проверка `--dist` на другой машине);
- **«Что уже не вопросы»** — список закрытого с замерами, чтобы человек не
  перепроверял сделанное.

Ссылка: <https://github.com/mavkasgit/ktm2000/issues/245>

## Почему так

Формат выбран по скиллу `grilling` (frontier + рекомендации + ожидание ответов),
место — по конвенции репозитория (`docs/agents/issue-tracker.md`: issues живут в
GitHub, метка `wayfinder:grilling` для HITL-решений). Каждый вопрос опирается на
факт этой ночи, а не на предположение: числа из `BASELINE.md`, тикеты — из
`docs/night/tickets/`.
