# T-378 — Операции анодирования: коды цветов и `updated_at`

Спека: `ekranchik-modern/docs/specs/0003-color-dictionary-and-third-party.md`.
Блокирует: T-379, T-381.

## Задача

Цвета анодирования должны существовать в KTM как операции участка
`ANODIZING` с прямыми кодами веера. Старые `ANOD_01…08` не переименовываются
и не удаляются. У операции появляется время изменения — по нему синк решает,
чья правка новее.

## Объём

### Модель и миграция

- Миграция `085` (следующая после `084`): `section_operations.updated_at`
  (`DateTime`, not null, server default `now()`, обновляется при UPDATE).
- Модель `SectionOperation` получает поле `updated_at`.
- Сид `SECTION_OPS` дополняется операциями участка `ANODIZING`:

| `operation_code` | `operation_name` | `icon_color` |
| ---------------- | ---------------- | ------------ |
| `C0` | Серебро | `#C2CAD3` |
| `C35` | Чёрный | `#4E4E52` |
| `S120-0` | Золото | `#E1DDB0` |
| `S120-2` | Старое золото | `#AD9E77` |
| `C31` | Светлая шампань | `#CFD4D5` |
| `C32` | Тёмная шампань | `#AEA895` |
| `C33` | Светлая бронза | `#716C62` |
| `C34` | Тёмная бронза | `#595655` |
| `C41` | Медь | `#A0837E` |
| `C44` | Тёмная медь | `#715C5F` |
| `C51` | Нержавеющая сталь | `#A9968E` |
| `C54` | Тёмный титан | `#766D6D` |

- Hex снят с бумажного веера ClassicELOX, он справочный: зависит от сплава и
  освещения. Официальные значения можно заменить одной правкой.
- Старые `ANOD_01…08` остаются как есть, включая `ANOD_06` «Шампань».
  `ANOD_04` не существует и не добавляется.
- Порядковые номера новым операциям не присваиваются: код — это и есть
  `operation_code`.

### Проверки

- `sections_seeder` обновляет существующие операции по
  `(section_id, operation_code)` и не удаляет отсутствующие в сиде.
- Повторный сид не плодит дублей.
- `updated_at` меняется при правке операции и не меняется при чтении.

### Тесты

- Сид создаёт 12 новых операций с кодами; старые 7 на месте.
- Уникальность `(section_id, operation_code)` не нарушена.
- `updated_at` заполнен и обновляется при изменении.
- `ANOD_04` отсутствует.

## Приёмка

1. В прод-БД есть операции `C0…C54` с названиями и hex.
2. Старые `ANOD_01…08` работают в маршрутах как раньше.
3. `updated_at` меняется при правке и читается синком.
4. `npm run db:seed` на dev не создаёт дублей.
