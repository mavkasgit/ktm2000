# T-380 — Сторонний 3D-заказ «урны» и ручная норма

Спека: `ekranchik-modern/docs/specs/0003-color-dictionary-and-third-party.md`.
Блокирует: T-381.

## Задача

В справочнике KTM появляется сторонний заказ: урны для ГорКомплекса. Завод их
не производит, только анодирует. Это 3D-объект в штуках, без длин. На подвес
идёт 4 комплекта по 2 предмета (корпус + крышка), итого 8. Норму нельзя
вывести формулой — её задают вручную.

## Объём

### Продукт

Данные прода (через UI «Продукты» или API, в репозитории — фикстура/тест):

- `sku = урны`, `name = Урны, комплект 2 шт (корпус + крышка)`;
- `type = component` — это сырьё заказчика, не ГП;
- `dimension_state = volume`, `unit = шт`, `lengths = []`;
- `attributes.third_party = true`, `attributes.customer = "ГорКомплекс"`;
- `attributes.pack = { "sets_per_hanger": 4, "pieces_per_set": 2 }`;
- `attributes.hanger_mode = "manual"`,
  `attributes.quantity_per_hanger = { "default": { "auto": null, "manual": 8 } }`;
- `source = manual`, `is_catalog_item = true`;
- цвет на продукте не задаётся: цвет — операция анодирования, а не свойство
  сырья.

### Норма

- Для `dimension_state=volume` разрешается ручная норма с ключом `default`:
  `hanger_mode=manual` + `quantity_per_hanger.default.manual`.
- Для `length` поведение не меняется: норма по длине, как сейчас.
- Если ручной нормы нет, для `volume` остаётся существующая формула по
  площади; ошибки нет, просто считается по формуле.
- Валидация «длины только для 1D» не меняется: `volume` + непустые длины —
  422.

### Тесты

- Создание продукта `урны` с `volume`, без длин, с ручной нормой 8.
- `GET /api/products/{id}` отдаёт `third_party`, `customer`, `pack`,
  `quantity_per_hanger.default.manual`.
- Расчёт нормы для `volume` с `default.manual` возвращает 8.
- `volume` + длины — 422.
- Обычный `length`-артикул считает норму как раньше.

## Приёмка

1. В KTM есть артикул `урны` без длин, в штуках, 3D.
2. Отметка стороннего заказа, заказчик и состав комплекта доступны в API
   карточки; отображение и ввод в UI KTM — отдельный тикет, в этом срезе
   данные заводятся через API/сид.
3. Норма на подвес — 8 (4 комплекта по 2).
4. Обычные артикулы и их нормы не изменились.
