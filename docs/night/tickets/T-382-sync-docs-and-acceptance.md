# T-382 — Документы синка и приёмка цветов/стороннего заказа

Спека: `ekranchik-modern/docs/specs/0003-color-dictionary-and-third-party.md`.
Зависит от: T-381.

## Задача

Описать новый контракт синка и проверить его на копии прод-БД и dev-стенде.
Без этого следующая правка синка снова забудет про цвета или безразмерные
артикулы.

## Объём

### Документы

- `docs/ekranchik-catalog-sync.md`:
  - таблица «Что синхронизируется»: артикул, наименование, длина, норма,
    фото, **цвета анодирования**;
  - правило «новее — правильнее» для цветов, равенство — локальная строка;
  - локальные цвета не удаляются; `--prune-orphans` их не трогает;
  - безразмерный артикул: норма из `default`, `length=NULL`;
  - старые `ANOD_*` и новые коды `C0…C54` живут вместе.
- `docs/catalog/` или `GLOSSARY.md`: короткая запись про сторонний заказ и
  комплект урн (2 предмета, 4 комплекта на подвес).
- Ссылка на спеку 0003 и ADR 0013 Экранчика.

### Проверка

- `npm run verify:ekranchik` на копии прод-БД: цвета и `урны` в расхождениях,
  без падений.
- `npm run sync:ekranchik -- --scope ekranchik` на dev: цвета и `урны`
  появились в SQLite Экранчика.
- Повторный `--check` чист.
- В Экранчике: `С32` → `C32`, карточка `урны` открывается из строки книги,
  норма 8.

## Приёмка

1. Документ синка описывает цвета и безразмерный артикул.
2. Синк на dev отрабатывает, повторный `--check` чист.
3. Ручная проверка Экранчика пройдена и описана в PR.
4. Старые артикулы и цвета не изменили поведение.
