# T-0021 — Канон frontend обещал обязательный `npm run dev` перед e2e

- **Категория:** документация по тестированию
- **Статус:** DONE (коммит см. `JOURNAL.md`)
- **Дата:** 2026-10-01, цикл 7
- **Файл:** `frontend/AGENTS.md` (раздел «E2E (Playwright)»)

## Проблема и доказательство

В каноне frontend раздел E2E заканчивался так:

```bash
npm run dev                              # сначала из корня
npm --prefix frontend run test:e2e
```

Это противоречит фактическому устройству прогона:

- `frontend/playwright.config.ts` объявляет **свои** `webServer` для backend и
  frontend с `reuseExistingServer: false` — Playwright поднимает стек сам
  (плюс отдельная БД `ktm2000_e2e` и свои порты, `frontend/scripts/run-e2e.mjs`);
- `frontend/e2e/AGENTS.md` прямо описывает это («свой стек», `PW_REUSE_STACK=1`
  как единственный обход) и приводит ручной `npm run dev` только в рецепте
  отладки против уже поднятого стека;
- `docs/testing-guide.md` формулирует то же: прогон «не трогает devstack».

То есть человек, следующий канону frontend, поднимал ненужный стек и получал
либо лишние занятые порты, либо ложное ожидание, что прогон переиспользует
его серверы (молча — нельзя, `reuseExistingServer: false`).

## План изменений

Раздел E2E в `frontend/AGENTS.md`:

- команда прогона — `npm --prefix frontend run test:e2e` с пометкой, что стенд
  поднимается сам (своя БД и порты);
- добавлено уточнение: ручной `npm run dev` нужен только для
  `PW_REUSE_STACK=1` (отладка), со ссылкой на `e2e/AGENTS.md`.

## Граница: что НЕ затронуто

- Код, конфиги Playwright, сами спеки, `e2e/AGENTS.md` — не менялись: правка
  только в разделе документации, который противоречил остальным документам.
- Ничего не удалено: прежняя команда заменена корректной, а сценарий ручного
  стека сохранён (с явной оговоркой).

## Критерии готовности (измеримые)

1. Утверждение канона совпадает с `playwright.config.ts`
   (`reuseExistingServer: false`, свои `webServer`) и с `frontend/e2e/AGENTS.md`.
2. В разделе есть и команда прогона, и оговорка про `PW_REUSE_STACK=1`.
3. Тесты не затрагиваются (правка документации).
