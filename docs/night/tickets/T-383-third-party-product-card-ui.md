# T-383 — Карточка артикула: сторонний заказ и ручная норма

Спека: `ekranchik-modern/docs/specs/0003-color-dictionary-and-third-party.md`.
Связанные: T-380 (данные и API), T-381 (синк в «Экранчик»),
[ADR-0075](../../adr/0075-default-norma-dlya-obemnogo-artikula.md).

## Задача

Данные стороннего заказа (`third_party`, `customer`, `pack`) и ручная норма
`quantity_per_hanger.default.manual` уже есть в API продуктов (T-380), но в
интерфейсе KTM их не видно и не ввести: заказ «урны» заводится только
запросом. Оператор справочника должен видеть, что артикул — материал
заказчика, и задавать норму на подвес руками, не уходя в API.

## Объём

### Карточка артикула

- В шапке/списке артикулов — бейдж «Сторонний заказ» и заказчик
  (`ГорКомплекс`); для обычных артикулов ничего не меняется.
- В форме (`CatalogForm`) — блок «Сторонний заказ»: галочка, заказчик,
  комплект (`sets_per_hanger`, `pieces_per_set`). Поля необязательные;
  снятая галочка очищает заказчика и комплект.
- Комплект показывается как «4 × 2 = 8 шт на подвес»; числа
  положительные, лишние ключи API не принимает (уже 422).

### Ручная норма

- Для `dimension_state=volume` без длин форма показывает поле «Норма на
  подвес (вручную)» и пишет `quantity_per_hanger.default.manual` при
  `hanger_mode=manual`.
- Для `length`/`area` поле скрыто: там норма по длине или формула листа.
- Если API ответил 422 (`default` не для `volume`, `default.manual` без
  `manual`), сообщение показывается в форме, данные не теряются.

### Тесты

- Карточка артикула с `third_party=true` показывает бейдж и заказчика;
  обычный артикул — нет.
- Форма отправляет `third_party/customer/pack` и очищает их при снятии
  галочки.
- `volume` + `manual` отправляет `default.manual`; `length` этого поля не
  показывает.
- 422 от API показывается текстом, форма остаётся заполненной.

## Приёмка

1. Заказ «урны» можно завести и поправить целиком через UI.
2. На карточке видны отметка стороннего заказа, заказчик и состав комплекта.
3. Норма на подвес — 8 (4 комплекта по 2), её видно и можно изменить.
4. Обычные артикулы и их нормы не изменились.

## Вне объёма

- Отдельный справочник заказчиков и история заказов.
- Показ отметки стороннего заказа в «Экранчике» — там её нет намеренно.
