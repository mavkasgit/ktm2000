## 3. Методика замера (общая для всех)

Счёт SQL — engine-слушатель + транзакция с откатом (методика #290):

```python
from sqlalchemy import event
from app.core.database import engine   # тот же engine, что у приложения

counts: list[tuple[str, float]] = []

@event.listens_for(engine.sync_engine, "before_cursor_execute")
def _before(conn, cursor, statement, parameters, context, executemany):
    conn.info.setdefault("t", []).append((statement, perf_counter()))

@event.listens_for(engine.sync_engine, "after_cursor_execute")
def _after(conn, cursor, statement, parameters, context, executemany):
    t0 = conn.info["t"].pop()
    counts.append((statement, perf_counter() - t0))
```

Формат результата — таблица в комментарии тикета: `запросов | мс` до и после,
с JSON-сверкой ответа (по `id`/`task_id`/`route_id`/`dimensions`).
Скрипт-мералка — throwaway в `docs/night/logs/` (каталог в `.gitignore`),
результаты и числа — в комментарий тикета и в `docs/night/BASELINE.md`.
