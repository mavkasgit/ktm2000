## Требует решения человека (BLOCKED_NEEDS_HUMAN)

1. **Изоляция ночного прогона.** Сейчас ночной оркестратор по инструкции
   работает в том же дереве и на той же ветке, что дневная сессия, — при живом
   WIP он стартовать не может вообще. Варианты: (а) запускать ночь только на
   чистом дереве (`git status --porcelain` пуст) и после подтверждения; (б)
   дать ночи отдельный worktree/клон (`git worktree add ../ktm2000-night -b
   night/$(date +%F)`) — тогда чужая работа в основном дереве не мешает.
   Второй вариант я считаю правильным для роли «работать всю ночь».
2. **Разрешение на нагрузку машины.** Если dev-стек поднят и человек за
   машиной, ночной прогон тестов конкурирует за ядра. Нужно правило: запускать
   тесты только при закрытом dev-стеке либо с `PYTEST_NUM_WORKERS` ≤ 4.
3. **CI (B-0001) и покрытие (B-0002)** — по ним нужно продуктовое решение
   (минуты CI, порог покрытия), поэтому они в BACKLOG, а не в работе.
