## 4. Гейты приёмки

1. Из `frontend/`: `npx tsc -p tsconfig.json --noEmit` — 0 ошибок (без `-p`
   проект не проверяется, PLAYBOOK §10.3).
2. Полный `npm --prefix frontend run test` (срез D) — passed/failed числами,
   число тестов не уменьшилось.
3. Из корня `backend/`: `ruff check .` **целиком**, не списком своих путей
   (PLAYBOOK §10.3); полный `npm run test:pytest` — числами.
4. Финал среза: `git merge main` → коммит (в этом порядке, не наоборот).
5. e2e — один прогон по очереди оркестратора, свой namespace, `workers=1`,
   `retries=0`, `CI=` пустым; в отчёте SHA, команда, workers, retries.
6. `npx @colbymchenry/codegraph sync` после правок кода.
7. Утверждение «готово» — числом/логом/выводом; «по коду видно» доказательством не
   является.
8. Тикет закрывается только после слияния: `git merge-base --is-ancestor <sha> main`.
9. Комментарий в свой issue: что сделано, чем доказано, что не сделано.

**Приёмка оркестратором** (PLAYBOOK §10.4): сверка заявленного с числами среза;
для каждого «красного» — контроль на чистой базе до правок; отрицательный
результат помечается явно.
