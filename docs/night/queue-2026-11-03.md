# Очередь волны night-2026-11-03 — тела тикетов

Разделитель: строка `%%%`. После неё — `заголовок | срез`, затем тело.
Номера присваивает GitHub (`gh issue create`); соответствие —
`gh issue list --search "night-2026-11-03" --json number,title`.
Поле `Срез`: оркестратор / A(CI) / B(frontend) / C(backend+infra) / D(docs).

Источники модели: [mokevnin/dev-quality-gates](https://github.com/mokevnin/dev-quality-gates)
(`mise.toml`, `hk.pkl`, `tools.json` + `check-registry.ts` + `readme.ts`, `freshness.ts`,
`docs/adopt.md`, `docs/not-adopted.md`, `CONTRIBUTING.md#selection-criteria`)
и `docs/night/BACKLOG.md` (B-N01…B-N14).

Три принципа донора, которые применяются ко всей волне (цитаты — в #360):

1. «A check that was never seen failing is not known to work» — каждый новый шаг
   гейта обязан иметь пробник, показавший красный ход.
2. «A hook is a convenience. A check that exists only in a hook is not enforced» —
   всё, что добавляется в хук, живёт и в CI.
3. Пороги свежести: `PUSH_DAYS=90`, `RELEASE_DAYS=365`, `REVIEW_DAYS=180`;
   последняя версия берётся из `releases?per_page=1`, а не из `releases/latest`.
