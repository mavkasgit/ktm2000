## 1. Preflight (обязателен, до первой правки)

**Главный риск этой ночи: основное дерево грязное, и целевые файлы тикетов
уже правит человек/параллельный агент.** На момент составления плана
(`git status`):

```
M frontend/src/features/reversal/pages/ActionsJournalPage.tsx
M frontend/src/features/reversal/pages/ActionsJournalPage.test.tsx
M frontend/src/features/reversal/components/JournalRowOperations.tsx
M frontend/src/features/reversal/components/AmendDialog.tsx
M frontend/src/features/sections/pages/AuditLogsPage.tsx
+ ~40 чужих файлов (backend/routes, seeds, execution, references, spg, transfers)
```

Правила:

1. **База веток срезов — SHA с уже закоммиченными правками человека.** Если к
   старту ветки они не закоммичены — стоп: срез не заводить, доложить
   владельцу. Работать поверх незакоммиченного WIP чужих файлов запрещено
   (PLAYBOOK §5).
2. `git status --short` в своём дереве = пусто; список чужих изменений в
   `main` — denylist до конца смены (правка даже точечная → стоп и доклад).
3. Frontend-зависимости: `npm ci --prefix frontend` в своём worktree (свой
   `node_modules`, junction не делать).
4. Нагрузка: dev-стек может жить всё время — каждый замер помечать
   «под нагрузкой».

## 3. Решения, зафиксированные гриллом (не пересматривать)

### 3.1 Волна 1 (UI-журналы)

| Вопрос | Решение |
|---|---|
| Плотность | `TABLE_ROW_DENSE`, 32px на обеих страницах |
| Новый тон | `ok` в `rowTones.ts` (эмеральд, **без** `line-through`), во все 5 словарей |
| Тоны — аудит | `success → ok`, `error → scrap`, `info → plain` |
| Тоны — отмена | `active → active`, `amended → activeRunning`, `reversed → completed`, `purged → waiting` |
| Статус в аудите | `Badge` вместо кружка-иконки (28px не влезает в 32px) |
| Панель аудита | `FiltersPanel`: search → `DateRangePicker` (custom) → 4 toggle со счётчиками, `onReset`; **печати и bulk нет**; в `ToggleTone` добавить зелёный (`emerald`) |
| Панель отмены | `FiltersPanel` с двумя `select` (тип, статус); **поиск НЕ добавлять** (`GET /actions` его не принимает) |
| Сортировка отмены | `sortField` ни у одной колонки (сервер жёстко `order_by id desc`); попаперы фильтров только на `action_type`/`status` |
| Карточка-обёртка аудита | убрать: раскладка `page-header` → `FiltersPanel` → `DATA_TABLE_STYLES.container` |
| Пусто/загрузка аудита | внутрь `tbody`, `colSpan`-строка; **тексты не менять** («История событий пуста.» vs «Нет записей, соответствующих фильтрам…») |
| Детальная строка | раскрытие остаётся: `colSpan`, авто-высота, `bg-muted/30`, основная строка 32px, без `font-medium` |
| Навигация | один пункт меню «Журнал» (`History`, `/audit-logs`); общий сегментированный переключатель в `shared/ui` в `page-header` обеих страниц; маршруты `/audit-logs` и `/reversal` **не менять**, редиректов нет |
| `BackButton` | только на `/reversal`, ведёт на `/audit-logs` |
| h1 | «Журнал действий» / «Отмена действий» — как есть; шапка — `page-header`/`page-title` |
| e2e | шаг 1 `reversal-journal.spec.ts` — клик «Журнал» → вкладка «Отмена действий» (`@smoke`, покрывает новую навигацию) |
| Юнит на аудит | добавить `AuditLogsPage.test.tsx` (фильтр → параметры запроса, пусто, раскрытие); e2e на аудит не плодить |
| #311 | радар, без AC исполнения; вливание остальных журналов — отдельное решение |

**Контракт, который ломать нельзя** (держат тесты): `action-row-{id}`,

### 3.2 Волна 2 (производственные тикеты)

| Вопрос | Решение |
|---|---|
| Эталон пар (#312) | Склейка пар при импорте **убирается**: две отдельные позиции → индивидуальные задания на всех участках. Группировка строк планов и «единый подвес» (`N×A + N×B`) на печати анодирования — **новый код отображения**. Код пар (`product_pairs`, resolver, миграция 058, ADR-0023/0024) **не удалять — обобщить** |
| Судьба тикета, если не успел | Fallback «принять с пометкой и закрыть» **отменён**: тикет не закрывается, состояние в «Журнале хода» |
| Prep-план (#313) | Обычный план со своим количеством, **без** «сверхплановой» семантики. Структура — «Упаковочная карта РП» с убранными лишними колонками; колонки операций остаются, операции — из файла (`resolve_operations`, дефолт участка — fallback) |
| Варианты маршрута prep | Ровно три, вместе не бывают: сверло+дробеструй / пресс+дробеструй / чистый дробеструй. Старт `RAW_STOCK`, финиш `PREP_STOCK` |
| Покрытие prep-маршрутов | Pytest — все три ветки правил; E2E — один, самый длинный (сверло+дробеструй) |
| Файл prep-плана | Новый xlsx в `frontend/e2e/testdata/` по образцу существующих (в git коммитятся) |
| Источники (#314) | Показ источника при взятии в работу + выбор оператором; предвыбор **глобальный**, по убыванию `completed_operations` (prep-склад выше сырья). `remainder_allocation` на бэке сейчас игнорируется — восстановить. Полный автоподбор — #282, **не закрывать и не дублировать** |
| Куда гоняется #315 | До `SHIPPED` (полный цикл); ассерт — источник `PREP_STOCK`, `RAW_STOCK` не участвует; числа в сценарии произвольные |
| Данные #312 | Строка плана 2604/2616 — имитация через API, конкретный файл не принципиален |
