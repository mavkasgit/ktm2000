# docs/frontend — «почему» к правилам фронтенда

Нормативные правила — в [`frontend/AGENTS.md`](../../frontend/AGENTS.md).
Здесь лежат обоснования, история и развёрнутые примеры: читать перед правкой
соответствующей области, а не постоянно.

| Файл | Когда читать |
|------|--------------|
| [`tables.md`](tables.md) | Таблица, колонка, шапка/фильтр, тулбар, массовый режим, группировка |
| [`quantity.md`](quantity.md) | Подпись размера, поле количества, правка факта, форматтеры вывода |
| [`dialogs.md`](dialogs.md) | Новое окно, панель, подтверждение |
| [`code-splitting.md`](code-splitting.md) | `Router.tsx`, `lazyRoute.tsx`, `main.tsx`, бюджет начального пакета |
| [`data-freshness.md`](data-freshness.md) | Кеш, ключи запросов, `staleTime`, «данные несвежие» |
| [`ui-prototypes.md`](ui-prototypes.md) | Макет или перерисовка экрана |
