# Прототипы UI — обоснования

Правила — в [`frontend/AGENTS.md`](../../frontend/AGENTS.md), раздел «Прототипы
UI». Здесь примеры и причина, почему правила экрана живут в репозитории.

**Когда читать:** перед макетом, прототипом или перерисовкой экрана, окна,
карточки; перед обсуждением «как должна выглядеть панель» без открытого
реального экрана.

- Перед макетом или прототипом экрана — открыть **реальный** экран в dev-стенде
  и прочитать реальный компонент. Прототип по памяти воспроизводит экран,
  которого нет: решение принимается по выдуманной панели, а расхождения с живым
  экраном всплывают уже в реализации.
- Окно/модалку прототипируют по её **фактической структуре**, а не «панелью с
  полями». Пример — карточка артикула
  ([`src/features/references/components/CatalogForm.tsx`](../../frontend/src/features/references/components/CatalogForm.tsx)):
  фото в колонке 320 px, поля в три колонки, блок размерности и норм, секция
  «Пары», «Примечания», футер с действиями. Макет без этих частей обсуждает не
  тот экран, который откроет оператор.
- Правила конкретного экрана живут здесь: глобальный скилл
  `~/.agents/skills/prototype` общий для всех проектов, и локальные пометки в
  нём теряются при его обновлении.
