# ADR-0069: Дневной план как живая группировка заданий

Дата: 2026-09-24. Статус: принято.
Перенумерован: файл лежал в `docs/adr/` как `0027-daily-plans-live-task-groupings.md`
без номера в заголовке, а 0027 занят решением об атрибуции break-glass-записей
(`0027-atribuciya-break-glass-zapisej-sluzhebnomu-polzovatelyu.md`, на него ссылаются
ADR-0005 и ADR-0006). Новый номер — следующий свободный, а не «исторический»:
0027 он никогда не был присвоен осознанно (#390, 2026-11-03).

DailyPlan сохраняет только участок, дату, автора, время создания и ссылки на WorkTask; состав всегда читается из актуальных заданий, без снимка полей задачи. Это позволяет прогрессу и завершению оставаться единым источником правды, сохранять завершённые строки в истории и не создавать расхождение между планом и участком. Состав допускает одинаковую дату у нескольких планов, но активная принадлежность задания уникальна; отзыв удаляет только membership и оставляет audit.
