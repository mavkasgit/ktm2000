# ADR-0074: `default` — ручная норма для объёмного артикула

Дата: 2026-11-18. Статус: принято.
Спека: `ekranchik-modern/docs/specs/0003-color-dictionary-and-third-party.md`.
Тикеты: T-380, T-381.
Связанные: ADR-0012 (размерности), ADR-0020 (размер 2D/3D — идентичность SKU),
ADR-0023 (пара `product_pairs`), ADR-0047 (норма на подвес).

## Контекст

`Product.attributes.quantity_per_hanger` исторически — карта
`{"<length_mm>": {"auto": N | null, "manual": N | null}}`: норма выбирается по
нормальной длине. Это работает для 1D-профиля, но не для 3D-объекта без длин.
Сторонний заказ «урны» — `dimension_state=volume`, `unit=шт`, без
`product_lengths`: норму 8 (4 комплекта по 2 предмета) не к чему привязать.
Формула листа даёт другое число, а оператору нужна именно ручная норма.

## Решение

Для `dimension_state=volume` разрешается ключ `default` в той же карте:

```json
{
  "default": { "auto": null, "manual": 8 }
}
```

Правила:

1. `default` принимается только у `volume`; у `length` и `area` — 422.
2. `default.manual` имеет смысл только при `hanger_mode=manual`; при `auto`
   API отвечает 422, иначе значение молча стало бы `None`.
3. Читатели, которые выбирают норму по длине, пропускают нечисловые ключи;
   `Product.quantity_per_hanger` для `volume` возвращает `default.manual`.
4. Синк в «Экранчик» для артикула без длин читает `default` и переносит
   норму в `profiles.quantity_per_hanger`.
5. Без `default` у `volume` остаётся прежняя формула по площади.

## Альтернативы

- **Синтетическая длина** (`0` или `1`) в `product_lengths` — отвергнуто:
  врёт про 3D и ломает проверку «длины только у 1D».
- **Отдельное поле `default_quantity_per_hanger`** — отвергнуто: плодит второй
  источник нормы и второй путь чтения; карта уже JSONB и допускает ключ.
- **Только формула по площади** — отвергнуто: для урн она даёт не 8 и не
  отражает комплекты.

## Последствия

- Карта `quantity_per_hanger` перестаёт быть строго «длина → норма». Каждый
  читатель, который перебирает её как длины, обязан фильтровать нечисловые
  ключи; это закреплено в `_is_numeric_key` и тестами.
- ADR-0023/0047 не отменяются: для 1D и 2D поведение прежнее, `default` —
  только ветка `volume`.
- В карточке артикула норма 8 должна отображаться как ручная; ввод в UI —
  отдельная задача, в этом срезе данные заводятся через API/сид.
- Синк T-381 читает `default.manual` для безразмерных артикулов; форма
  `{"default": {"auto": null, "manual": 8}}` — контракт.
