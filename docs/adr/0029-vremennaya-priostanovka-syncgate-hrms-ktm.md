# ADR-0029: Временная приостановка Syncgate HRMS/KTM

Дата: 2026-09-25. Статус: принято.

Обязательная синхронизация KTM-2000 с соседним HRMS временно приостановлена: KTM
развивается автономно, а `../hrms` больше не является рабочей зависимостью.
`verify-sync`, манифест и тесты сохранены для возможного возврата.

## Решение

Автоматические lifecycle-гейты вызывают `verify-sync.mjs --if-enabled`. Без
`KTM_SYNCGATE` проверка пропускается; значения `1`, `true`, `yes`, `on` без учёта
регистра включают её. Неподдерживаемое значение завершает команду ошибкой, чтобы
опечатка не отключала проверку незаметно. Ручной `npm run verify:sync` остаётся
принудительным и не зависит от переключателя.

## Рассмотренные варианты

- Оставить гейт включённым по умолчанию и отключать его в каждом окружении:
  отклонено, оставляло зависимость от второго workspace.
- Удалить механизм и второй workspace: отклонено как необратимое изменение при
  временной потребности.
- Ввести явный переключатель и сохранить ручной режим: принято.

## Последствия

ADR-0007 и ADR-0011 сохраняют архитектурное решение для возможного возврата,
но их обязательный build-enforcement приостановлен. KTM-2000 можно запускать и
собирать без `../hrms`; расхождение общей копии auth-shell не блокирует команды.
