# ADR-0029: Временная приостановка Syncgate HRMS/KTM

Дата: 2026-09-25. Статус: принято. ADR-0029 (amended 2026-11-18).

## Поправка

Исходное решение ниже сохранено как история. Фактическое поведение изменено:

- **pre-push проверяет shared-файлы безусловно.** Переменная `KTM_SYNCGATE`
  больше не выключает проверку на push: момент push — последний, когда
  расхождение общей копии ещё можно заметить. Переключатель остался только у
  `predev`/`prebuild` как лёгкий локальный путь.
- **Известный долг фиксируется снимком, а не путём.**
  `scripts/sync-baseline.json` хранит `path`, `kind`, `hash` (sha256
  локального файла на момент снимка), `reason`, `reviewed` и `expires`
  (2027-06-30). Сравнение идёт по `path + kind + hash`: правка файла на
  известном пути меняет hash и роняет прогон, а не проходит зелёной. Записи
  без `kind`, `hash`, `reviewed` или `expires` — ошибка конфигурации (exit 2);
  снимок пересобирается осознанно флагом `--update-baseline`.
- **pre-push не требует соседа.** Проверка вызывается с `--optional`: если
  `../hrms` в клоне нет, печатается причина и хук пропускает шаг (exit 0).
  Ручной `npm run verify:sync` остаётся строгим — без соседа exit 2.
- **CI `sync.yml` — report-only.** Джоб `sync` не входит в required checks,
  причина — второй репозиторий живёт своим циклом, а красный по чужому
  состоянию не должен блокировать merge. Дата пересмотра — 2027-06-30, та же,
  что у baseline. На PR сознательно сравнивается default-ветка `hrms`, а не
  одноимённая: иначе отсутствие такой ветки давало бы ложные красные.

## Решение (2026-09-25)

Обязательная синхронизация KTM-2000 с соседним HRMS временно приостановлена:
KTM развивается автономно, а `../hrms` больше не является рабочей зависимостью.
`verify-sync`, манифест и тесты сохранены для возможного возврата.

Автоматические lifecycle-гейты вызывают `verify-sync.mjs --if-enabled`. Без
`KTM_SYNCGATE` проверка пропускается; значения `1`, `true`, `yes`, `on` без учёта
регистра включают её. Неподдерживаемое значение завершает команду ошибкой, чтобы
опечатка не отключала проверку незаметно. Ручной `npm run verify:sync` остаётся
принудительным и не зависит от переключателя.

## Рассмотренные варианты

- Оставить гейт включённым по умолчанию и отключать его в каждом окружении:
  отклонено, оставляло зависимость от второго workspace.
- Удалить механизм и второй workspace: отклонено как необратимое изменение при
  временной потребности.
- Ввести явный переключатель и сохранить ручной режим: принято.
- (2026-11-18) Вернуть безусловную проверку на push, а «шум» известного долга
  гасить снимком с содержимым и сроком пересмотра: принято вместо
  выключения проверки.

## Последствия

ADR-0007 и ADR-0011 сохраняют архитектурное решение для возможного возврата,
но их обязательный build-enforcement остаётся приостановленным: KTM-2000 можно
запускать и собирать без `../hrms`. При этом push и CI проверяют дрейф
shared-файлов, а известный долг виден в `scripts/sync-baseline.json` вместе с
причиной и датой пересмотра.
