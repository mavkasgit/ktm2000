# Dev-инструменты backend (#377): чем проверяем, а не на чём крутится приложение.
#
# Почему отдельный файл. До #377 версии инструментов жили только в телах
# workflow: `pip install ruff==0.16.9` — `.github/workflows/ruff.yml:45`,
# `pip install coverage==7.17.2` — `.github/workflows/backend-tests.yml:73`
# (решение #245 Q21: «отдельным pip install, requirements/Docker не трогаем»).
# Локально у этих версий не было источника: `ruff` из PATH и `ruff` из CI могли
# разойтись, а «какой версией снят ноль находок» был видно только из CI. Теперь
# пин один, и workflow берут его отсюда (#362/#364 — правку шагов делает срез A,
# этот файл её ждёт).
#
# Как применять.
#   локально (в свой venv, поверх runtime-зависимостей):
#       python -m pip install -r backend/requirements.txt -r backend/requirements-dev.txt
#   в CI — второй install рядом с существующим:
#       pip install -r backend/requirements-dev.txt
#   проверить совпадение версии с файлом:
#       ruff --version && python -m coverage --version
#
# Пины = фактические версии `backend/.venv` машины (замер 2026-11-03,
# `pip list --format=freeze`, Python 3.12.10): конфликт с установленным
# окружением нет — `pip install --dry-run` по этому списку даёт
# «Requirement already satisfied» по всем пяти pytest-слоям и «Would install
# ruff-0.16.9» только для ruff (в venv его нет, он в системном Python, и там
# ровно 0.16.9). Ничего не переустанавливалось.
#
# Чего здесь сознательно нет.
#   * Runtime-зависимостей (fastapi/sqlalchemy/alembic/…) — они в
#     `requirements.txt` с нижними границами; перепинивание основного слоя —
#     отдельный тикет, не этот.
#   * `alembic`: drift-гейт (`migrations.yml`: `alembic check`) использует
#     runtime-версию из `requirements.txt`, дублировать её пином здесь значило
#     бы создать второй источник правды.
#   * npm-слоя (lefthook, markdownlint-cli2, Playwright) — он в
#     `package.json`/`frontend/package.json`, вне backend.

-r requirements.txt

# Линтер backend. Пин совпадает с `ruff.yml` (`pip install ruff==0.16.9`):
# на 0.16.9 снят ноль находок и посчитан скоуп `ruff.toml`, на другой версии
# «красный/зелёный» может разойтись с CI.
ruff==0.16.9

# Coverage-гейт CI (`backend tests`: `coverage run --source=app -m pytest`,
# `coverage report --fail-under=73`). Пин = решётка #245 Q21: бейзлайн 73%
# снят именно на 7.16.2 (docs/night/BASELINE.md), поэтому версия — часть
# замера, а не деталь окружения.
coverage==7.17.2

# Тестовый раннер и плагины. В `requirements.txt` они объявлены нижними
# границами; здесь закреплены те версии, на которых снят канон pytest
# (`backend/tests/AGENTS.md`), потому что от них зависит и дефолт `--dist
# loadfile`, и `-p no:pytest-testmon` в CI.
pytest==9.2.0
pytest-asyncio==1.4.1.post1
pytest-xdist==3.8.0
pytest-testmon==2.3.0
